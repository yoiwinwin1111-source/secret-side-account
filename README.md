# 小号正在输入 · Secret Side Account

独立 CP 手机模拟器首版。A 与 B 同团、秘密恋爱，玩家是 A，B 在后段才知道小号身份。

已实现：A/B 名字、团名及三个 Instagram 账号和 X 小号的昵称、用户名、头像设置；锁屏/桌面/图标；Instagram 日常发布、相册选图、本地压缩、个人主页；X 发帖/引用/点赞/收藏/搜索/评论；分批评论、独立讨论串与回流、B 私聊、八段故事骨架。

公开关键动态：25 条直接评论（含回复）、4 条外部讨论各16条评论及 B 私聊。普通日常与私密动态分别处理。初始12条信息流帖子。所有内容与热度均为虚构本地模拟；不会发往真实社交平台。头像、照片、进度保存在当前浏览器。平台账号设置不会读取真实账号。

当前为可玩首版：八段剧情仍是骨架，评论素材需要继续扩展和精修；尚未实现多图轮播、独立快拍查看器、复杂掉马分支、音乐/通话。大号主页的生活卡片是示意内容。无后端、无真实社交登录。

入口为根目录 index.html，无构建依赖。旧项目 whereweleftoff 与尤伊未改动。

验证：脚本检查默认信息流、自定义称呼、私密隔离、公开评论三轮联动、B消息与事件只执行一次；浏览器实际完成设置和发布。实体 iPhone Safari 未验证。
